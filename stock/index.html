          Costos

          Falta crear la tabla de costos en Supabase (SQL Editor → pegar la parte «COSTOS» de supabase.sql → Run).

          Todavía no cargaste tu Excel de costos.

          Tocá Cargar Excel y elegí «Costos Penitentia.xlsx». Cada pestaña del Excel aparece acá, con las mismas fórmulas: cambiás un precio y se recalcula todo.

          Las celdas amarillas se editan: tocá una, escribí y apretá Enter. Todo lo que depende de ese valor se recalcula al instante.
